# In Case

A detective-style contact book for networking: contacts are suspects, coffees and 1-1s are missions, and what you learn becomes clues on a case wall.

It is a single static page (`index.html`), so it works on GitHub Pages with no build step.

## Good to know

- Your contacts, facts and clues are saved in your browser (localStorage) on the device you use. Nothing is uploaded, so the public repo contains only the app code, not your data.
- Data does not sync between devices, and clearing your browser data deletes it. Use one device and one browser.
- The site shares browser storage with any other pages under `YOUR-USERNAME.github.io`. If you host other projects there, they could read this app's data.
